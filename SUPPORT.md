# Support

Thank you for using **Ikigai no Ma**.

Ikigai Garden is a quiet, Japanese-inspired reflection app designed around Ikigai, Ma, poetry, ritual, seasons, sound, and an inner garden. The app is intended as a calm digital space for self-reflection and personal orientation.

## Getting Help

If you experience a technical problem, have found a bug, or would like to request a feature, please use one of the following options:

* Open an issue in this GitHub repository
* Contact support via the official project website
* Include as much relevant information as possible so the issue can be reproduced

## Before Opening an Issue

Please check whether:

* You are using the latest available version of the app
* The issue still occurs after restarting the app
* The issue is already listed in the existing GitHub issues
* The problem is reproducible on your device

## What to Include in a Bug Report

When reporting a bug, please include:

* App version
* iOS version
* Device model
* A short description of what happened
* Steps to reproduce the issue
* Screenshots or screen recordings, if helpful
* Any relevant console logs, if available

Please avoid sharing sensitive personal content from your reflections, poems, notes, or journal entries unless it is absolutely necessary for understanding the issue.

## Feature Requests

Feature ideas are welcome, especially if they fit the philosophy of the app:

* calm interaction
* Japanese-inspired aesthetics
* reflection without pressure
* privacy-conscious design
* poetic and meaningful user experience
* simplicity over unnecessary complexity

Please describe what you would like to see, why it would be useful, and how it could support the quiet character of the app.

## Privacy

Ikigai Garden is designed with privacy in mind. Personal reflections, poems, notes, and ritual entries should remain personal.

When submitting support requests, please do not include private journal content, personal health information, or other sensitive data unless you deliberately choose to do so.

## Scope of Support

Support is available for:

* App crashes
* Layout or display issues
* Asset or visual problems
* Navigation problems
* Saving or loading issues
* Accessibility concerns
* General usability feedback

Support does not include medical, psychological, therapeutic, or crisis intervention advice. Ikigai Garden is a reflection and wellbeing companion, not a medical or therapeutic product.

## Response Time

This is an independently developed project. I will do my best to review issues and respond as soon as possible, but response times may vary.

Thank you for helping improve Ikigai Garden.
